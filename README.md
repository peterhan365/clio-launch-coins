# 코인 배분 앱 — 아, 클리오다! 런칭 워룸

GitHub Pages 로 바로 열리는 참가자용 앱입니다. 화면은 이 저장소가, 기록은 Google Apps Script 웹앱(구글 시트)이 맡습니다.

- 참가자: `index.html` (Pages 주소 그대로)
- 진행자: 주소 끝에 `#admin`
- 기록 서버 연결: `config.json` 의 `"endpoint"` 에 Apps Script 웹앱 주소를 넣고 커밋합니다. 또는 주소 끝에 `?api=…` 를 한 번 붙여 열어도 됩니다.
- `Code.gs`: 구글 시트 → 확장 프로그램 → Apps Script 에 붙여 넣고 웹앱으로 배포합니다. 절차는 운영 안내 문서 2장.

개인정보는 받지 않습니다(팀 번호·브랜드 이름·코인 숫자만). 검색 엔진 색인은 막아 두었습니다.
